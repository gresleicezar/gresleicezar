Projeto real desenvolvido para apresentar produtos personalizados da VAIDEBOX e gerar novos contatos comerciais.

### 🛠️ Tecnologias

`React` • `TypeScript` • `Vite` • `Tailwind CSS` • `Vercel`

- 📱 Interface totalmente responsiva
- 📦 Catálogo de produtos personalizados
- 💬 Integração com WhatsApp

- 🤝 Programa Empreenda Box
- 📝 Formulário para captação de leads

- 🌐 Domínio personalizado
- 🚀 Deploy contínuo com GitHub + Vercel
- 🔀 Fluxo de desenvolvimento utilizando Git Branches
